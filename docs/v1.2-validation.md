## Mechanical Crafter Reproduction Matrix

- Valid recipe: arrange a Mechanical Crafter grid that produces a vanilla shaped recipe and confirm output matches Create alone.
- No recipe: arrange an invalid grid and confirm the server does not crash and the crafter returns no output.
- Partial grid: leave holes in a shaped grid and confirm no output unless Create alone would craft it.
- Modified during tick: change one input stack while the crafters are attempting to assemble and confirm no stale output is produced.
- Identical grids: run two identical grids in the same tick and check `/cao stats` for Crafter hits.
- Multiple dimensions: repeat one valid and one invalid grid in Overworld and Nether and confirm `/cao stats` records independent lookups without cross-dimension output.
- Disabled cache: set `optimizations.processingRecipeMemoization.enabled=false`, reload config/restart, and confirm `/cao stats` Crafter lookups do not increase during crafting.

Record:

- average MSPT;
- median MSPT;
- high percentiles when available;
- maximum MSPT;
- `/cao stats` hit/miss/negative/eviction/invalidation counts;
- profiler active versus inactive impact;

Do not publish a percentage gain unless the raw measurements and scenario are recorded with the result.
